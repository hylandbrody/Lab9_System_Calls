# Programs
info.c – Displays system information, including the hostname, operating system, CPU count, and memory.

pinfo.c – Displays information about a process using its PID.

pmod.c – Changes the process priority and sleeps for a specified amount of time.

finfo.c – Displays information about a file, including its permissions, size, and modification time.
